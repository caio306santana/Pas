Guia de Setup — Execute esses passos para rodar o sistema

1
Instalar Node.js LTS
O Node.js não está instalado no sistema. Baixe o instalador oficial LTS (v20+) e execute. Reinicie o VS Code depois.
🌐 https://nodejs.org/en/download
Após instalar, verifique: node -v && npm -v
2
Iniciar banco de dados (Docker)
Na pasta raiz do projeto, suba o PostgreSQL e o Redis com Docker Compose. Se não tiver Docker, baixe em docker.com.
$ docker-compose up -d
3
Instalar dependências do Backend
Acesse a pasta backend/ e instale os pacotes (NestJS, Prisma, Socket.IO, BullMQ etc.)
$ cd backend && npm install
4
Criar banco de dados + Seed do Menino Travesso
Execute as migrations do Prisma para criar as tabelas no PostgreSQL e popule com dados iniciais do trailer.
$ npx prisma migrate dev --name init
$ npm run db:seed
5
Iniciar o Backend (NestJS API)
Rode o servidor em modo desenvolvimento. A API estará em localhost:3001 e o Swagger em localhost:3001/api/docs.
$ npm run start:dev
6
Instalar + iniciar o Frontend (Next.js)
Em um segundo terminal, vá para a pasta frontend/, instale as dependências e suba o servidor. O site estará em localhost:3000.
$ cd ../frontend && npm install && npm run dev
7
Testar o sistema completo
Abra os links abaixo para confirmar que tudo está funcionando:
CARDÁPIO DIGITAL localhost:3000/t/menino-travesso
SWAGGER API DOCS localhost:3001/api/docs
PAINEL ADMIN localhost:3000/admin/login
